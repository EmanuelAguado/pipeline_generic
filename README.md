# Generic Pipeline Template

This repository contains the generic and abstract pipeline codebase used as the foundation for all productions.

The goal of this template is to provide a reusable, production-ready pipeline architecture that can be adopted as-is or customized to meet the specific requirements of a project, studio, or production.

## Framework

This pipeline is developed using the **GwaIO Framework**, which provides the core infrastructure, tools, integrations, and workflows required for production environments.

### Resources

* Documentation: https://emanuelaguado.github.io/gwaio-docs

> [!IMPORTANT]
> This repository should remain as generic and production-agnostic as possible. Any production-specific logic, configuration, or customization should be implemented in dedicated project repositories whenever feasible.
